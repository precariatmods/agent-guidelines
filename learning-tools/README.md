# Learning Tools

このフォルダは学習用サンプルの入口です。

教材を新しく作る場合、または既存教材の指導方法を変更する場合は、最初に[guideline.md](guideline.md)を読みます。
固定教材の構造化、学習段階ごとの教師ロール、AIによる対話指導、必要に応じた視覚実験、理解度判定、学習レポートに関する共通方針は、`guideline.md`を正本とします。
各教材は、共通自動化モデル`Input → Skill + Policy → Output`に沿って整理します。
文章中心の非プログラム教材や企業研修にも対応し、「知る・覚える・理解する・応用する・整理する・人に説明する」を基本の学習段階とします。以下の地図は、現在収録されている数学・物理のサンプルです。

## 地図

```text
learning-tools/
├─ math/      数学
└─ physics/   物理
```

利用者の目的に合わせて `math/` または `physics/` の `README.md` を読んでください。
必要のない分野の詳細は先に読み込まなくて構いません。

各教材では、処理を始める前に教材フォルダの`Output.md`を確認します。成果物と保存場所はそのファイルを唯一の正本とし、変更する場合も先に`Output.md`へ反映します。

フォルダ名は、同じ種類のものを先頭語で判別しやすくする命名も使用できます。
例：`function_...`、`mechanics_...`。
これは必須規則ではなく、このサンプルで整理しやすくするための例です。
