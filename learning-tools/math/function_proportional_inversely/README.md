# 反比例：一定の道のりを進む速さと時間から考える

教材ID：`inverse-proportional-travel` / 版：0.1（教材作成者の確認前の設計案）

一定の道のり120 kmを一定の速さで進む場面を入口に、速さが何倍になると時間は逆数倍になること、一定の積、式 `y＝a/x`、表、グラフ、順方向・逆方向の計算を結び付ける教材です。

中心となる考え方は「反比例する二量を選ぶ」「一方が何倍なら他方はその逆数倍」「積 `xy` は一定で、その値は場面で保たれている全体量を表す」の3点です。休憩や速度変化は含めず、固定問題では正の速さと正の時間だけを扱います。

対象学年は未指定です。小数・分数の四則計算、速さ・道のり・時間の関係、単位、座標を扱う学習者を想定します。速さ0 km/hでは120 kmを進み終えないため、主題の定義域は `x＞0` です。
