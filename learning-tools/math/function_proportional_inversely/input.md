# Input：反比例

- 教材ID：`inverse-proportional-travel`
- 版：0.1（設計案）
- 固定教材の正本：`input/student-sheet.md`
- 指導手順・ヒント・解答・判定基準の正本：`work/guideline.md`
- 成果物：`Output.md`の各IDを参照。

到達目標は、現実の場面から反比例する二量を選び、逆数倍、一定の積、式 `y＝a/x`、表、グラフを相互に結び付け、未知量を順方向・逆方向に求め、比例や反比例でない場合との違いを説明できることです。

固定する主題は「一定の道のり120 kmを、途中で速さを変えず、休憩せずに進むときの速さと時間」です。速さを `x` km/h、時間を `y` 時間とします。`xy＝120` で、120の単位と意味は道のり120 kmです。

対象学年は未指定です。小数・分数の乗除、速さ・道のり・時間、単位、座標を前提として確認します。負の速さ・負の時間は扱わず、主題の定義域は `x＞0` とします。

知識単位はU1（二つの量と逆数倍）、U2（一定の積と保たれる全体量）、U3（反比例の式）、U4（表・式・グラフ）、U5（順方向・逆方向）、U6（比例・反比例の判定）、U7（成立条件と現実のモデル）です。

利用者が新しい入力を用意する必要はありません。教材の数値や題材を差し替える場合は、生徒用問題、教師用解答、ヒント、グラフ、単位、判定基準の整合性を再確認します。
