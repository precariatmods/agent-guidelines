# Processing：反比例

Skillは、前提の再生確認、場面からの二量と固定量の抽出、逆数倍と積の計算、反比例定数の単位と意味の解釈、表・式・グラフの相互変換、未知量の順方向・逆方向の計算、誤答診断、段階的ヒント、学習記録の整理です。使用順序と条件は`work/guideline.md`に従います。

表やグラフを生成する場合は、次を仕様とします。

- 横軸を速さ `x`（km/h）、縦軸を時間 `y`（時間）とし、軸名と単位を省略しない。
- `y＝120/x` について、`(20, 6)`、`(30, 4)`、`(40, 3)`、`(60, 2)`、`(80, 1.5)`、`(120, 1)`の対応を確認できるようにする。
- 現実の主題では `x＞0, y＞0` の部分だけを表示する。x＝0の点を置かず、負の速さを現実のデータとして扱わない。
- 点を直線で結んで反比例を直線の関係と誤認させない。軸に近づいても軸とは交わらないことを、有限の速さでは時間が正であることと結び付ける。
- 図や計算結果は、学習者の初回予想後に検証用として使う。形だけで反比例と判定せず、積と場面の固定量を確認する。
- 定数120には `km`、求めた量には `km/h` または `時間` を付け、数値だけの一致で判定しない。

プログラムを追加する前に`Output.md`へ成果物を定義します。計算ロジックと画面制御を分離し、描画上の丸め値を正解判定に使いません。
