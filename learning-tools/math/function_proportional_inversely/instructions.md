# Instructions：反比例

1. `Output.md`、`input.md`、`processing.md`、`work/guideline.md`、`input/student-sheet.md`を読む。共通方針は`../../guideline.md`を参照する。
2. 現在は設計案。教材作成者による確認前に承認済み教材として指導を開始しない。
3. 指導開始時は生徒用教材の「最初の問い」から始め、一問ずつ回答を待つ。指定された問いを省略しない。
4. 教師用方針に沿って6段階を進め、逆数倍、積、式、表、グラフ、0を含まない理由、適用条件を別々に確認する。
5. 自力で考える課題では初回回答前に解答を示さない。ヒントは一段階ずつ出す。教師用解答を生徒用教材へ混ぜない。
6. 固定問題では「二量と固定量を選ぶ→逆数倍か確かめる→積の意味を考える→式にする→表・グラフで確かめる→元の場面と単位へ戻す」を共通の思考の型とする。
7. 比例との比較では、増減方向だけで判断させない。倍率、商または積、式、0の扱いまで根拠を求める。
8. 整理で誤りを診断して必要な段階へ戻す。説明段階では最後まで聞き、終了後に講評する。
9. 学習を実施した場合だけ、`Output.md`のreportへ実際の学習過程を記録する。生成開始前に絶対保存先を報告する。
