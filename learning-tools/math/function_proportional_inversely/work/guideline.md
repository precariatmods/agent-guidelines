# 反比例：教師用方針

教材ID：`inverse-proportional-travel` / 版：0.1（設計案）

共通方針は`../../../guideline.md`。問題・前提の正本は`../input/student-sheet.md`、成果物は`../Output.md`を参照します。導入、課題、ヒント、解答、判定基準は教材作成者による確認前です。

## 範囲と説明上の注意

一定の道のり120 kmを、途中で速さを変えず、休憩せずに進むときの速さと時間を扱います。現実の定義域は `x＞0`、値域は `y＞0` です。負の速さ、負の時間、負の定数は固定問題に含めません。

反比例は「一方が増えると他方が減る関係」ではありません。倍率が逆数になること、積 `xy` が一定であること、`xy＝a` または `y＝a/x` と表せることを結び付けます。

定数120は無単位の数字ではありません。`(km/h)×時間＝km` なので、固定された道のり120 kmです。比例の「1あたり」と反比例の「保たれる全体量」を混同させないようにします。

速さ0 km/hでは120 kmを進み終えないため、有限の所要時間は決まりません。「0で割れない」という式の理由と、場面の理由を両方説明させます。グラフは軸に近づきますが軸上の点を含みません。

## 6段階の進行

### 1. 知る

必ず生徒用教材の最初の問いを出し、時速120 kmと30 kmについて予想と理由を待ちます。式を先に教えません。

- 期待する予想：時速120 kmは2倍の速さなので1時間、時速30 kmは半分の速さなので4時間。
- 「速くなるから短くなる」だけなら、何倍かを問い返し、増減と反比例を区別する必要を把握する。
- 現実の安全性や法定速度の議論へ広げず、一定の速さという数学モデルの条件を明示する。

### 2. 覚える（U1〜U3）

生徒用教材のU1〜U3を少数ずつ提示します。最初に次の3点だけを確認します。

1. 反比例では一方がk倍なら他方は `1/k` 倍。
2. `xy＝a` が一定。
3. 式は `y＝a/x` で、x＝0は使わない。

その後、「120は何を表すか」「単位は何か」「速さ0を使えないのはなぜか」を一問ずつ確認します。言葉、式、単位を正確に再生できたら理解へ進みます。理由の導出はこの段階で要求しません。

### 3. 理解する（U1〜U4）

U1からU4を順に扱い、初回回答後に必要なら表やグラフで検証します。

- U1：速さが2倍、3倍、0.4倍なら時間は1/2倍、1/3倍、2.5倍。
- U2：`60×2＝120`、`30×4＝120`。単位はkm、意味は固定された道のり120 km。
- U3：`xy＝120`、`y＝120/x`。xとyの意味と単位も言わせる。
- U4：yは順に6、4、3、2、1.5、1。右下がりの滑らかな曲線上に並び、直線ではない。軸上の点は含まない。

ヒントは「元の何倍か」→「同じ120 kmを進むには時間はどう補うか」→「速さ×時間は何を表すか」の順に出します。表、式、グラフが別々の事実ではなく、一定の積を表すと説明できれば通過です。

### 4. 応用する（U5〜U7）

- U5：`120÷1.5＝80` より時速80 km。`80×1.5＝120` で検算する。
- U6：不正解。増減方向だけでなく、逆数倍、一定の積、`y＝a/x` を確かめる必要がある。
- U7：固定した道のりを一定の速さで休憩なく進むという条件が必要。休憩を含む全所要時間や途中で変わる速さを、一つのxと `y＝120/x` で直接表すことはできない。

U7では平均の速さの新しい指導へ広げません。反比例モデルが成立する条件を選び、条件から外れた場合に同じ式を機械的に使わないことを重視します。

### 5. 整理する

固定問題Q1〜Q7を順に一問ずつ提示します。以下は教師用の要約です。

| ID | 解答・判定要点 |
|---|---|
| Q1 | 時速30 kmは4時間、40 kmは3時間、80 kmは1.5時間、120 kmは1時間。60 km/hを基準に逆数倍を対応させる。 |
| Q2 | 例：`30×4＝60×2＝120×1＝120`。単位はkm、固定された道のり120 km。 |
| Q3 | `xy＝120`、`y＝120/x`。時速48 kmでは2.5時間。 |
| Q4 | `120÷1.5＝80` より時速80 km。`80×1.5＝120` で検算する。 |
| Q5 | どの組も積が120。xが2倍になるとyは半分、4倍になると4分の1。 |
| Q6 | 言い切れない。逆数倍、一定の積、式、固定された道のりと一定の速さという条件を確かめる。 |
| Q7 | 道のり120 kmが一定、途中で速さを変えない、休憩を所要時間に含めない。x＝0では式が0除算となり、場面でも目的地へ到着しないため有限のyが決まらない。 |

各問で、結論だけでなく、対象の二量、逆数倍または積、式、単位、場面への戻し、成立条件を評価します。

| 誤り | 最初のヒント | 戻り先 |
|---|---|---|
| 減れば反比例と判断する | 速さが2倍なら時間は正確に何倍ですか | 理解（U1） |
| 速さが2倍で時間も2倍にする | 同じ道のりを進むのに、速くなったら長くかかりますか | 覚える（U1） |
| 商を一定にしようとする | 速さ×時間は何を表しますか | 理解（U2） |
| 定数120の単位や意味がない | `(km/h)×時間` の単位を計算してください | 理解（U2） |
| `y＝120x` とする | x＝60を入れると2時間になりますか | 理解（U3） |
| x＝0の点を置く | 時速0 kmのままで到着できますか | 理解（U3・U4） |
| 休憩込みでも同じ式を使う | その時間は走行時間だけですか | 応用（U7） |

原因が不明なら診断質問を先に行います。戻った段階の確認後、同じ整理問題でもう一度、自力で理由を再構成させます。

### 6. 人に説明する

生徒用の最終説明課題を提示し、説明終了までヒントや訂正を挟みません。終了後に次を一問ずつ確認します。

1. 「一方が増え、他方が減る」だけでは、なぜ反比例と言えないのか。
2. 定数120の単位と意味は何か。
3. x＝0を使えない理由を式と場面でどう説明するか。
4. 比例と反比例では、倍率と一定になる計算がどう違うか。

伝達の品質と教材整合性を別々に評価します。逆数倍、一定の積、式、曲線、0、適用条件が因果関係としてつながり、比例との違いを説明できれば十分理解です。

## 比例教材との接続

比例教材を実施済みの場合だけ、次を追加で比較します。

| 観点 | 比例 | 反比例 |
|---|---|---|
| 倍率 | xがk倍ならyもk倍 | xがk倍ならyは1/k倍 |
| 一定になる量 | `y÷x` | `xy` |
| 式 | `y＝ax` | `y＝a/x` |
| 定数の意味 | 1あたりの量 | 保たれる全体量 |
| 0 | x＝0ならy＝0 | x＝0は使えない |
| グラフ | 現実の範囲では原点から伸びる直線の一部 | 現実の範囲では軸と交わらない曲線 |

比例側の記憶を前提にせず、履歴または回答で到達を確認してから比較します。
