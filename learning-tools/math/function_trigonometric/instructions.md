# Instructions：三角関数

このファイルは、AIが教材を実行するときの手順の正本です。教育上の理由、ヒント、解答、判定基準は`work/guideline.md`を参照し、このファイルへ重複させません。

## 開始前

1. `Output.md`、`input.md`、`processing.md`、`work/guideline.md`、`input/student-sheet.md`を読む。共通方針は`../../guideline.md`を参照する。
2. 現在は教材作成者による確認前の設計案である。正式な授業用として承認済みとは扱わない。ただし、利用者が学習開始を依頼した場合は試行学習として開始し、設計案であることを理由に概要説明だけで停止したり、開始許可を聞き直したりしない。
3. `Output.md`の`intro-figure`で定義された表示用画像が実在することを確認し、対話画面で表示するための絶対パスを解決する。

## 初手の必須ルール

利用者が「三角関数について教えて」など、学習開始を依頼したときは、次をすべて守る。

1. 最初のメッセージの先頭に`intro-figure`の表示用画像を添付・表示する。
2. 同じメッセージ内で、画像の直後に最初の問いを一問だけ提示する。
3. 最初に尋ねるのは、オレンジ色の横線の変化だけとする。
4. 「長くなる・短くなる・変わらない」の選択肢を示し、予想でよいと伝える。
5. 縦線、理由、公式、詳しい定義は、最初の回答より前に質問・説明しない。
6. 問いを出したら、説明を続けずに回答を待つ。
7. 画像なしで問題文だけを出したり、画像のパスだけを記載したりしない。画像を表示できない場合は出題を進めず、そのことを利用者へ伝える。

### 初手の完成例

実際の応答では、角括弧の説明を表示用画像そのものへ置き換える。

> ［`intro-figure`の表示用画像］
>
> この図を一緒に見てみましょう。
>
> 黒い点Pが円の右端から上へ動くとき、まずオレンジ色の横線はどうなると思いますか？
>
> 「長くなる・短くなる・変わらない」から、予想で選んでください。

### 初手として不適合な例

- 画像を表示せず、文章だけで始める。
- 三角関数の定義や公式を先にまとめて説明する。
- 横と縦を同時に質問する。
- 最初の問いで理由まで求める。
- 問いを出した直後に、AI自身が答えやヒントを続ける。

## 最初の回答後

1. 横線への回答を受け止めてから、青色の縦線について同じ三つの選択肢で一問だけ尋ねる。
2. 縦線への回答を待ってから、二つの予想の理由を一問だけ尋ねる。
3. 「分からない」も回答として受け止め、正答を要求しない。理由への回答後に`output/circle-sin-simple.htm`を開き、予想を確かめる。
4. simple版では「角度 θの入力欄を見つける」→「数字を一つ入力する」→「点の位置を見る」→「横を見る」→「縦を見る」の順に、一文・一操作・一質問ずつ進める。一度に複数の角度や質問を出さず、値の暗記や計算は求めない。

## その後の進行

1. 教師用方針に沿って「知る・覚える・理解する・応用する・整理する・人に説明する」の6段階を進める。暗記の再生と理由の説明を区別し、各段階の到達根拠を記録する。
2. 予想や自力で考える課題では、初回回答前に解答を示さない。ヒントは一段階ずつ出す。確認問題の教師用解答を生徒用教材へ混ぜない。
3. 覚える段階の主要角にもsimple版を使う。多機能な`output/circle-sin.html`は一般角・負の角、および理解・応用・整理の検証に使う。
4. Q1〜Q6では「sinは縦、cosは横」→「中の角をφと置く」→「θの範囲をφへ変換する」→「円弧から候補をすべて探す」→「θへ戻して検算する」の順を共通の思考の型とする。90°を加えてsinとcosを入れ替える公式や加法定理へ広げない。Q7だけは、sinとcosが混ざった式を一種類にそろえる応用として扱う。
5. HTMLへ入力する角度範囲は、常に問題に書かれた元のθの範囲とする。問題のθの範囲を度へ直して「θの開始」「θの終了」へ設定し、開始・終了を含むかも問題の不等号に合わせる。
6. 中の角φ＝aθ＋bを使う問題では、学習者が先にφの範囲を計算し、その後で元のθの範囲とa、bをHTMLへ設定する。画面に表示されるφの範囲が事前の計算と一致するか確認する。計算後のφの範囲をθの入力欄へ直接入れない。
7. 整理で誤りを診断して必要な段階へ戻す。説明段階では最後まで聞き、終了後に講評する。
8. 利用者が学習レポートの保存を依頼した場合だけ、`Output.md`の`report`へ実際の学習過程を記録する。生成開始前に絶対保存先を報告する。保存依頼がない通常の試行学習では、対話だけを進めてレポートファイルを生成しない。
