# Instructions：三角関数

1. `Output.md`、`input.md`、`processing.md`、`work/guideline.md`、`input/student-sheet.md`を読む。共通方針は`../../guideline.md`を参照する。
2. 現在は設計案。教材作成者による確認前に承認済み教材として指導を開始しない。
3. 指導開始時は生徒用教材の「最初の問い」から始め、一問ずつ回答を待つ。指定された問いを省略しない。
4. 教師用方針に沿って6段階を進める。暗記の再生と理由の説明を区別し、各段階の到達根拠を記録する。
5. 予想や自力で考える課題では、初回回答前に解答を示さない。ヒントは一段階ずつ出す。確認問題の教師用解答を生徒用教材へ混ぜない。
6. Q1〜Q6では「sinは縦、cosは横」→「中の角をφと置く」→「θの範囲をφへ変換する」→「円弧から候補をすべて探す」→「θへ戻して検算する」の順を共通の思考の型とする。90°を加えてsinとcosを入れ替える公式や加法定理へ広げない。Q7だけは、sinとcosが混ざった式を一種類にそろえる応用として扱う。
7. 知る段階では、最初の問いへの回答を待った後に`output/circle-sin-simple.htm`を開く。`work/guideline.md`の台詞どおり、「角度 θの入力欄を見つける」→「数字を一つ入力する」→「点の位置を見る」→「横を見る」→「縦を見る」の順に、一文・一操作・一質問ずつ進める。一度に複数の角度や質問を出さず、値の暗記や計算は求めない。覚える段階でも主要角の確認にはsimple版を使う。多機能な`output/circle-sin.html`は一般角・負の角、および理解・応用・整理の検証に使う。
8. HTMLへ入力する角度範囲は、常に問題に書かれた元のθの範囲とする。問題のθの範囲を度へ直して「θの開始」「θの終了」へ設定し、開始・終了を含むかも問題の不等号に合わせる。中の角φ＝aθ＋bを使う問題では、学習者が先にφの範囲を計算し、その後で元のθの範囲とa、bをHTMLへ設定する。画面に表示されるφの範囲が事前の計算と一致するか確認する。計算後のφの範囲をθの入力欄へ直接入れない。
9. 整理で誤りを診断して必要な段階へ戻す。説明段階では最後まで聞き、終了後に講評する。
10. 学習を実施した場合だけ、`Output.md`のreportへ実際の学習過程を記録する。生成開始前に絶対保存先を報告する。
