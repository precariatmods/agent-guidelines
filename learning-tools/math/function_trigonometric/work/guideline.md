# 三角関数：教師用方針

教材ID：`trigonometric-sin-cos` / 版：0.1（設計案）

共通方針は`../../../guideline.md`。利用者指定の指導順序を具体化したものです。導入・段階別課題・ヒント・判定基準は教材作成者による確認前です。問題・前提の正本は`../input/student-sheet.md`、成果物は`../Output.md`を参照します。

## 範囲と説明上の注意

sin・cosの意味から、固定問題Q1〜Q7を解いて説明するところまで扱います。tan、加法定理・倍角公式の暗記、異なる角のx-y軌跡は対象外です。sin(2θ)を解くために倍角公式へ展開しません。

この教材の中心は、sinを円上の点の縦座標、cosを横座標として読み、中の角が変わると円上の点がどの範囲をどの速さで動くかを考えることです。`sin(θ＋π/2)＝cos θ`のようにsinとcosを入れ替える公式や、波形の平行移動を中心にはしません。Q4〜Q6の加減算も、別の公式への変形ではなく、円上で始まる角が変わることとして扱います。

横・縦は符号付き座標であり、通常の非負の距離と区別します。正の係数rについて、r sin φ・r cos φは半径rの円の縦・横の座標です。「2 sin 60°では半径を1から2にする」と説明し、単位円で定義されたsin自体の定義が変わるとは説明しません。負の係数を負の半径と呼びません。この教材の固定問題の外側の係数は正です。

φ＝aθ＋bでは、aはθに対する角の進み方、bはθ＝0での角です。区間がθ＝0から始まらない場合の実際の開始角はaθの下端＋bで求めます。bをそのままθ軸上の平行移動量と呼ばないこと。2 sin θとsin(2θ)を明確に区別します。

HTMLへ入力する角度範囲は、常に問題に書かれた元のθの範囲とします。φの範囲は学習者が先に計算し、元のθの範囲とa、bをHTMLへ設定した後、画面に表示されたφの範囲と照合します。計算後のφの範囲をθの入力欄へ直接入れません。

## 6段階の進行

### 1. 知る

必ず生徒用教材の最初の問いから始めます。担当は「まずは予想で大丈夫です。円の右端にある点が、上まで動くとします。横の長さと縦の長さは、どう変わりそうですか」と、短く区切って尋ねます。「理由も言えそうですか」と続けるのは、最初の回答を待ってからです。「分からない」も回答として受け止め、「では、図を動かして一緒に見てみましょう」と進めます。ここでは正答を要求せず、sin・cosの公式や結論を先に教えません。

回答後に`output/circle-sin-simple.htm`を開きます。担当は次の台詞と順番を基本とし、一文ごとに学習者の操作または回答を待ちます。

1. 「いまの予想を、円の図を動かして確かめます。」
2. 「画面の上に『角度 θ』と書かれた入力欄があります。見つかりましたか。」と聞き、返事を待つ。
3. 「その欄には、角度の数字を一つだけ入れます。°の記号は入れなくて大丈夫です。」
4. 担当が入力欄へ`0`を入れて見せ、「黒い点が円の右端にあります。オレンジ色の横がcos、青色の縦がsinです。」と伝える。
5. 「では、入力欄の数字を`90`に変えてください。入力すると図がすぐに変わります。」と伝え、操作が終わるまで待つ。
6. 「黒い点は、円のどこへ動きましたか。」と一問だけ聞く。回答後に「オレンジ色の横はどうなりましたか」、さらに回答後に「青色の縦はどうなりましたか」と一問ずつ聞く。
7. 同じ方法で`180`を入力させ、点の位置、横、縦を一問ずつ確認する。
8. 次に`30`、`45`、`60`を一つずつ入力させる。各回とも「点はどこですか」→「横はどれですか」→「縦はどれですか」の順で聞く。
9. 最後に`120`、`135`、`150`を一つずつ入力させ、「点が左側に来ると、横のcosの符号はどうなりましたか」と聞く。

一度に複数の角度や質問を並べません。「ここをクリックしてください」のような曖昧な指示を避け、「『角度 θ』の入力欄」「数字を90に変える」のように、場所と操作を具体的に言います。操作に迷った場合は、数学の説明を続けず、「入力欄は見つかりましたか」→「いま何の数字が入っていますか」→「その数字を消して90と入力してください」の順で一つずつ支援します。

知る段階では、値の暗記や計算を求めません。円上の点が動くこと、横がcos、縦がsinであること、第2象限では横が負になることに気付けば十分です。範囲、係数、中の角、波形、多機能版の操作は教えません。

### 2. 覚える（U1・U2）

最初に`Output.md`の`intro-figure`で定義した静止画1枚を表示します。θの位置を理解済みと仮定せず、「θは、中心Oで右向きの横軸から半径OPまで反時計回りに測る角度」と、図の弧を指して説明します。図はこの段階で渡す前提の提示であり、予想を検証する実験とは区別します。

その図を見せたまま「まずは、円を見ながらこの3つを覚えましょう」と伝え、半径は1、横の座標がcos θ、縦の座標がsin θの3点だけを提示します。θの場所が分からない場合は図へ戻り、数値の暗記や正誤確認を先へ進めません。

主要角の確認には引き続き`output/circle-sin-simple.htm`を使います。まず0°、30°、45°、60°、90°を入力し、次に120°、135°、150°、180°へ広げます。ここでの使用は、正解を先に示す検証実験ではなく、前提の提示と再生確認です。一般角・負の角へ進むときに初めて`output/circle-sin.html`へ切り替えます。

θの位置と横・縦の対応を確認したら、まず0°・30°・60°・90°の値を覚えます。値の正本は生徒用教材U2の表です。30°では`output/images/right-triangle-30.svg`、60°では`output/images/right-triangle-60.svg`を示し、斜辺・となり側・向かい側の比からsinとcosを対応させます。45°を追加するときは`output/images/right-triangle-45.svg`を示します。少数ずつ図と値を対応させ、HTMLでも同じ角へ点を動かして位置を確認します。その後、覚える担当が「cos 30°はいくつですか？」のように一度に一つの値を質問します。cosとsinを同時に答えさせることを最初の必須形式にはしません。

最初の確認順はcos 0°、sin 0°、cos 30°、sin 30°、cos 60°、sin 60°、cos 90°、sin 90°とします。毎回回答を待ってから正誤を伝えます。まだ提示していない値を暗記済みと仮定して出題しません。

暗記確認時は、数値表やHTML上の数値をそのまま読ませません。値を隠した図、導入図、または円上の位置だけを手掛かりに再生させます。支援が必要なら「cosは横でしたね」「θの場所を見てみましょう」と図やHTMLの位置へ戻します。それでも思い出せなければ値を短く再提示し、他の問題を挟んで再確認します。直後の復唱だけでは定着したと判定しません。

8つの値を確認後、同じ項目を順不同でも出し、横と縦を取り違えずに再生できるか確認します。ここでは理由の導出まで要求せず、理由を問われた場合は理解段階で扱う問いとして残します。

その後、`output/images/unit-circle-0-to-180.svg`とsimple版を併用して0°〜180°を見通し、90°では(0, 1)、180°では(−1, 0)を確認します。確認問題で必要な45°は`output/images/right-triangle-45.svg`、第2象限の120°・135°・150°はそれぞれ`right-triangle-120.svg`・`right-triangle-135.svg`・`right-triangle-150.svg`を使い、基準角の辺の比と「第2象限ではcosは負、sinは正」を結び付けます。simple版でも同じ角へ点を動かし、横座標の符号が変わることを確認します。その後、度とラジアン、象限の符号へ進みます。「cos 150°」「sin 150°」「πラジアンは何度か」「その点はどこか」も一問ずつ確認します。前提を正確に再生できたら理解へ進みます。

Q1とQ4に必要な範囲だけ、一般角もここで確認します。正の角は反時計回り、負の角は時計回り、一周2πを足し引きした角は同じ位置です。これは別の公式として暗記させず、HTMLで円上の点を実際に一周以上動かしたり、負の角へ動かしたりして確認します。「一周を超えても同じ円を続けて回る」「負なら反対向きへ回る」を自分の言葉で説明できれば十分です。

### 3. 理解する（U3・U4）

生徒用のU3、U4の順に、**予想→HTMLの設定→操作による検証→理由の説明**を行います。覚える段階ですでにHTMLを使用していますが、自力で考える課題では初回回答より先にHTMLの数値や軌跡を答えとして読ませません。

`output/circle-sin.html`では、問題に書かれた元のθの範囲を度に直し、「θの開始」「θの終了」に設定します。U3では係数（半径）と表示（sinまたはcos）を設定します。U4でφ＝aθ＋bを扱う場合は、まず紙面または対話でφの範囲を求め、その後で元のθの範囲とa、bをHTMLへ設定します。画面に表示されたφの範囲が事前の計算と一致するかを確かめます。計算後のφの範囲をθの入力欄へ入れません。HTMLはφの範囲を先に計算する装置ではなく、計算を円弧・座標・グラフで検証する装置として使います。

- U3の期待説明：2 sin 60°は半径2の縦で√3、3 cos 45°は半径3の横で3√2/2。角を一定にして半径だけを変えると、座標が同じ倍率で変わる。
- U4の期待説明：2θ・3θ・θ/3の増分はθの増分の2倍・3倍・1/3倍。2θ＋αはθ＝0でαから始まる。
- 範囲変換の期待値：π/3≦2θ＋π/3≦5π/6。下端・上端の両方に同じ操作をする。

ヒントは「横か縦か」→「角を保って半径だけ変えると？」、または「θの両端を代入してみよう」→「間の角は連続して増えるか」の順に出します。式の値だけでなく、係数と中の角の役割の違い、両端の変換を自力で説明できれば通過です。

### Q1〜Q6で繰り返す共通の思考

Q1〜Q6は別々の公式で解かせず、毎回次の順で説明させます。

1. sinなら縦、cosなら横の座標を見る。
2. 外側の係数は座標の倍率、中の係数は角の進む速さとして区別する。
3. 中の角をφと置く。
4. θの下端と上端を代入し、不等号と開閉端点を保ってφの範囲を求める。
5. 許された円弧を最後までたどり、必要な座標をとる位置をすべて探す。最大・最小では端点と、円弧内で縦・横が最も大きくなる位置も比べる。
6. φをθへ戻し、元の式、θの範囲、端点の条件で検算する。

学習者が途中で止まったときは、答えを補う前に、どの番号まで自分で説明できたかを確認します。

### 4. 応用する（U5・U6・U7）

生徒用のU5〜U7を順に扱います。今回確認したU1〜U4と、前提確認済みの代数を参照し、学習者自身に使う知識を選ばせます。他教材の履歴がない場合に既習と推測しません。U5・U6は予想後にHTMLへ元のθの範囲を設定して検証します。中の角を使う場合はa、bも設定し、表示されたφの範囲を事前の計算と照合します。U7ではcos²θ＋sin²θ＝1と `−1≦cos θ≦1` を、半径1の円と「Q7（cosだけ）」表示のcosの線で確かめます。平方完成とQ7の式への置換は、実際にQ7を扱う整理段階で導く。

- U5：π/6、5π/6。縦が同じ点を両方探し、範囲で選ぶ。
- U6：最大1（θ＝0）、最小−1（θ＝π）。円全体の値域だけでなく、指定円弧上で実現するか確かめる。
- U7：cos²θ＋sin²θ＝1を三平方から導かせ、−1≦t≦1を確認する。Q7は「sinとcosが混ざっているので、一種類にそろえられないか」という発想を選ぶ応用とする。未習なら、Q7とは別の補助例 `z＝2−(t−1/2)²`、`−1≦t≦1` を使い、平方完成後に頂点と端点を調べる見方を扱う。この補助例では最大2（t＝1/2）、最小−1/4（t＝−1）。Q7の完成解答を先に見せない。

方程式はφを置く→範囲を変換→学習者がφの範囲を確認→HTMLには元のθの範囲とa、bを設定→表示されたφの範囲を照合→円弧をたどる→円上の候補をすべて選ぶ→θへ戻す→元の範囲と式で検算、と進めます。最大・最小もHTMLには元のθの範囲を設定し、円弧の端と区間内の極値候補を調べ、対応するθも求めます。両端だけの比較で終えず、sin・cosが±1となる内部の角、または二次式の頂点を必ず候補に加えます。各方法を理由付きで使えたら整理へ進みます。

### 5. 整理する

固定問題Q1〜Q7を順に一問ずつ提示し、初回の回答を待ちます。問題をその場で別の問題へ差し替えません。方程式・最大最小の各問では、初回回答後にHTMLへ問題に書かれた元のθの範囲を設定します。中の角φ＝aθ＋bを使う場合はa、bも設定し、問題の不等号に合わせてθの開閉端点も設定します。画面に表示されたφの範囲が事前の計算と一致することを確認し、候補の網羅と端点・内部候補を検証してから理由を説明させます。φの範囲をθの入力欄へ直接入れません。以下の解答は教師用です。

| ID | 中間結果 | 解答 |
|---|---|---|
| Q1 | φ＝3θ、0≦φ＜3π。cos φ＝1/2よりφ＝π/3, 5π/3, 7π/3 | θ＝π/9, 5π/9, 7π/9 |
| Q2 | φ＝2θ、0≦φ＜2π。φ＝π/3, 2π/3 | θ＝π/6, π/3 |
| Q3 | φ＝θ/3、π/6≦φ＜π/3。cos φ＝√3/2よりφ＝π/6 | θ＝π/2 |
| Q4 | φ＝3θ−π/6、−π/6≦φ≦4π/3。cos φ＝−1/2よりφ＝2π/3, 4π/3 | θ＝5π/18, π/2 |
| Q5 | φ＝θ＋π/4、π/4≦φ≦3π/4 | 最大1（θ＝π/4）、最小√2/2（θ＝0, π/2） |
| Q6 | φ＝2θ＋π/6、π/6≦φ≦2π/3 | 最大√3（θ＝0）、最小−1（θ＝π/4） |
| Q7 | t＝cos θ、−1≦t≦1。y＝2−t²−t＝9/4−(t＋1/2)² | 最大9/4（θ＝2π/3, 4π/3）、最小0（θ＝0, 2π） |

Q1は中の角が一周を超えるため7π/3を落とさないこと。Q4は負の開始角を消さず、上端4π/3を含むこと。Q7は最大値をとる二つの角と、最小値をとる0と2πをすべて確認します。

表は採点用の要約です。解説するときは、Q1〜Q6について共通手順の順序を省略しません。特にQ1では、φが0から3πまで進むため、最初の一周にあるπ/3、5π/3だけで止めず、次の一周に入った7π/3まで円弧をたどります。Q4では、φの開始が−π/6であることを残し、時計回り側から4π/3までの円弧全体を見て2π/3と、閉じた上端4π/3を選びます。Q5・Q6では端点の値だけを機械的に代入せず、円弧の内部に縦または横がさらに大きくなる位置があるかを確認します。

Q7を提示した整理段階で、sinとcosが混ざった式を見せて最初に「式の中にsinとcosの二種類があります。一種類にそろえるとしたら、何を使えそうですか」と質問する。学習者がcosに着目できなければ、「あとで `t＝cos θ` と置きたいので、sin²θをcosだけで表せないでしょうか」と一段階だけヒントを出す。これは90°を加えてsinとcosを入れ替える変形ではなく、単位円の三平方をもう一度使う応用である。

関係式を答えた後は、次のつながりを一段ずつ説明させます。

1. `sin²θ＝1−cos²θ` としてcosへそろえる。
2. `t＝cos θ` と置く。一周の間にcosは−1から1までの値をすべてとるため、`−1≦t≦1`。
3. `y＝2−t²−t＝9/4−(t＋1/2)²` と平方完成する。
4. 頂点`t＝−1/2`は範囲内なので最大値は9/4。最小値は端点を比べ、`t＝1`で0となる。
5. `t＝−1/2`から最大値をとるθ＝2π/3, 4π/3へ、`t＝1`から最小値をとるθ＝0, 2πへ戻す。

その後にQ7（cosだけ）表示を使い、凡例でcosの線とyの線を区別しながら候補を確かめる。最初から置換後の完成式や平方完成を提示しない。

各問で、結論、角または置換変数の範囲、座標・関係式を使う理由、候補の網羅、元のθへの復元を評価します。単語の有無や解答の一致だけで合格にしません。

| 誤り | 最初のヒント | 戻り先 |
|---|---|---|
| 横・縦、典型値、象限の符号を混同 | 円上の点を座標で言ってみよう | 覚える（U1・U2） |
| 2 sin θとsin(2θ)を混同 | 変えているのは半径か角か | 理解（U3・U4） |
| 範囲や開閉端点を変換しない | θの両端を中の式に入れよう | 理解（U4） |
| 解を一つだけ選ぶ、複数周を落とす | 指定された円弧を最後までたどろう | 応用（U5） |
| 無条件に最大1・最小−1とする | その座標をとる角は今回の範囲内か | 応用（U6） |
| Q7でsin²θを置換できない | 半径と二つの座標に三平方を使おう | 応用（U7） |
| 計算はできるが根拠の順序がつながらない | 範囲、候補、θへの復元を順に説明しよう | 整理を続ける |

原因が不明なら診断質問を先に行います。戻った段階で確認後、同じ整理問題で再確認します。支援直後の丸写しではなく、自力で理由を再構成できることを確認します。

### 6. 人に説明する

生徒用の最終説明課題を提示し、説明終了までヒントや訂正を挟みません。終了後に「なぜ最大値をいつも1にできないのか」「中の角に複数の候補があるとき、どう確かめるか」を一問ずつ質問します。

伝達の品質（用語を説明する、筋道が追える）と教材整合性（符号付き座標、半径と角の区別、範囲・条件・解答の正しさ）を別々に評価します。原則として前段階へ戻さず、未達点と復習案を記録します。説明が苦手というだけで理解不足と断定せず、基準未達を合格にも扱いません。
