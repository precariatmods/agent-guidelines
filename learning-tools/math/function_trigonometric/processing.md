# Processing：三角関数

Skillは、前提の再生確認、座標と式の言い換え、問い、誤答診断、段階的ヒント、角の範囲の計算、解の検算、図による検証、学習記録の整理です。使用順序と条件は`work/guideline.md`に従います。

HTML・JavaScriptによる視覚実験は、導入用の`circle-sin-simple`と検証用の`circle-sin`に分けます。知る段階では、`intro-figure`とともに横、縦、理由を一問ずつ尋ねた後にsimple版を使い、0°〜180°の角度を一つ入力するだけで、円上の位置、横座標cos、縦座標sinを対応させます。範囲、係数、中の角、波形は表示しません。覚える段階の主要角にもsimple版を使い、画面上の答えを読むだけにならないよう、位置を見た後に値を隠して再生させます。一般角・負の角と、理解以降の検証には多機能版を使います。

HTMLへ入力する角度範囲は、常に問題に書かれた元のθの範囲です。横軸のθの開始・終了（−720°〜720°）と各端点を指定し、中の角を `φ＝aθ＋b`（a＝1/3、1、2、3、bは度）へ変換して円弧と波の軌跡を示します。計算後のφの範囲をθの入力欄へ入れません。φの範囲は、学習者が紙面または対話で先に求め、その後で元のθの範囲とa、bを設定し、画面に表示されたφの範囲が事前の計算と一致するかを確認します。

画面にθとφの範囲を併記するため、たとえば `0°≦θ≦360°` で `φ＝3θ` を選ぶと、φが0°〜1080°を動き、同じθの範囲に波の3周期分が現れることを確認できます。端点は塗りつぶしを「含む」、白抜きを「含まない」として円とグラフに表示します。sinは縦の座標、cosは横の座標として表示し、正の係数は円の半径と振幅に同じ倍率を適用して、比較時の座標の縮尺を固定します。sin・cosを同時表示する場合もx-y軌跡は作りません。

半径の係数変更は現在の軌跡全体に反映します。中の角の係数・位相を変えたときは、現在のθから軌跡を描き直します。「範囲を設定」は開始角へ戻り、その開始角から終了角までだけを再生・描画します。「軌跡を消す」は角度を保ったまま軌跡を消し、その位置から新しく描きます。動きを減らす端末設定では自動再生を30°ずつの手動送りへ置き換えます。

Q7では表示を「Q7（cosだけ）」に切り替えると、半径1の円でcos θを確認しながら、`2−cos²θ−cosθ` の値を同じθの範囲でグラフに表示します。凡例でcosの線とQ7の値（y）の線を区別します。これは `t＝cos θ` の範囲を確かめ、関係式による置換と二次式の候補比較を説明するために使います。厳密な最大・最小の判定は描画の丸めではなく、`−1≦t≦1` と平方完成による計算で行います。

視覚実験を拡張する場合は以下を仕様とします。

- 単位円と同じ角の拡大円で、横・縦の符号付き座標を示す。縦横の縮尺を等しくする。
- 半径と中の角φ＝aθ＋bを別々に操作できるようにし、一度に変える条件は一つとする。
- HTMLの角度範囲入力は常にθとし、θの区間とφの区間を並べ、端点の包含・除外、複数周、負の角を表示する。
- 覚える段階から角度操作を使い、典型角・象限・一般角を円上の位置と結び付ける。
- 最大・最小では、許される円弧と座標の範囲を示す。異なる角を組み合わせたx-y軌跡を追加しない。
- 自力で考える課題の検証用描画は予想後に行う。覚える段階の操作は前提の提示・再生確認として使い、答えを画面から読むだけにしない。
- 最初の問いでは`intro-figure`を必須とする。その後に画像を再表示できない場面では、既に確認した図の内容を座標の数値表と対話で補える。
- 計算・MatplotlibのFigure生成とStreamlitの画面制御を分離する。描画の丸めで厳密値や端点の包含を判定しない。
- 教師AIが操作状態を取得できない場合は、生徒から値を報告してもらい、画面が見えると仮定しない。

実装を追加する前に`Output.md`へ成果物を定義する。Pythonを使う場合は教材の`.venv`と`requirements.txt`で環境を管理する。
