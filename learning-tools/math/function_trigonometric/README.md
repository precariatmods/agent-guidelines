# 三角関数：単位円から方程式・最大最小へ

教材ID：`trigonometric-sin-cos` / 版：0.1（教材作成者の確認前の設計案）

sin・cosを単位円上の符号付きの横・縦の座標として捉え、係数による半径の変化、角度の変化、角の範囲の変換を経て、方程式と最大・最小を解く教材です。tanは学習対象にも問題にも含めません。異なる角を横・縦に用いたx-yの軌跡は扱いません。

中心となる考え方は「sinは縦、cosは横」「中の角が3倍なら円上の点は3倍の速さで進む」「先に中の角の範囲を求め、その円弧全体から候補を探す」の3点です。90°を加えてsinとcosを入れ替える公式や加法定理へは広げません。Q7だけは、sinとcosが混ざった式を単位円の関係で一種類にそろえる応用として扱います。
