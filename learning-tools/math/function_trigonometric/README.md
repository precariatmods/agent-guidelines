# 三角関数：単位円から方程式・最大最小へ

教材ID：`trigonometric-sin-cos` / 版：0.1（教材作成者の確認前の設計案・試行学習可）

## このサンプルの目的

このサンプルの主目的は、ChatGPTに三角関数の知識を説明させることだけではありません。教育方針、実行手順、問題、成果物を役割ごとに整理すると、AIの教え方をどこまで再現可能に制御できるかを確認することです。

たとえば「三角関数について教えて」という同じ依頼でも、このガイドラインを使う場合は、文章だけで一度に説明せず、指定された図を最初の問いと一緒に表示し、一度に一つだけ質問して回答を待ちます。この観察可能な違いが、ガイドラインを使う意味です。

版0.1は正式な授業用として承認されていませんが、利用者が学習開始を依頼した場合は、ガイドラインの動作確認を兼ねた試行学習を開始できます。「確認前の設計案」であることを理由に、教材概要の説明だけで停止しません。学習レポートは利用者が保存を依頼した場合だけ生成します。

## 初手で確認できる違い

| ガイドラインを使わない一般的な応答 | このガイドラインを使う応答 |
|---|---|
| 文章だけで定義や公式をまとめて説明することがある | 指定された単位円の図を最初に表示する |
| 横・縦・理由を同時に質問することがある | 横について一問だけ質問して回答を待つ |
| AIが独自の順番で説明する | 生徒用教材と実行手順で定めた順番を守る |

sin・cosを単位円上の符号付きの横・縦の座標として捉え、係数による半径の変化、角度の変化、角の範囲の変換を経て、方程式と最大・最小を解く教材です。tanは学習対象にも問題にも含めません。異なる角を横・縦に用いたx-yの軌跡は扱いません。

中心となる考え方は「sinは縦、cosは横」「中の角が3倍なら円上の点は3倍の速さで進む」「先に中の角の範囲を求め、その円弧全体から候補を探す」の3点です。90°を加えてsinとcosを入れ替える公式や加法定理へは広げません。Q7だけは、sinとcosが混ざった式を単位円の関係で一種類にそろえる応用として扱います。

対象学年は未指定です。分数・平方根・一次方程式・不等式・座標を扱う学習者を想定し、必要な前提を確認します。

指導前に[共通方針](../../guideline.md)と上記の文書を確認します。利用者が指定した目標に加え、導入問題・支援・評価の設計案を具体化しています。正式な授業用として公開・運用する前には教材作成者が確認します。確認問題7問のPDFとLaTeX原稿を作成済みです（成果物ID：`questions-pdf`・`questions-tex`、保存先は`Output.md`参照）。知る・覚える段階には角度入力だけの導入版（成果物ID：`circle-sin-simple`）、理解以降には範囲・係数・中の角・軌跡を扱う検証版（成果物ID：`circle-sin`）を使います。
