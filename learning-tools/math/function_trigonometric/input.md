# Input：三角関数

- 教材ID：`trigonometric-sin-cos`
- 版：0.1（設計案）
- 固定教材の正本：`input/student-sheet.md`
- 指導手順・ヒント・解答・判定基準の正本：`work/guideline.md`
- 成果物：`Output.md`の各IDを参照。

出典は、利用者がこの教材の制作時に提示した「三角関数教材の方針」と、金沢工業大学「KIT数学ナビゲーション」の[三角関数の方程式に関する問題](https://w3e.kanazawa-it.ac.jp/math/category/sankakukansuu/question/sankakuhouteisiki.html)です。tanの問題は除外し、sin・cosの方程式と最大・最小の出題形式を参考に、係数・角度・右辺・区間の数字を変更した7問をQ1〜Q7としました。参照元と同一問題の転記ではありません。

到達目標は、sin・cosの方程式と最大・最小を、単位円と角の範囲を根拠に解き、第三者へ説明できることです。Q7には単位円の関係式と二次式の最大・最小を使う補助学習を加えます。

対象学年は未指定です。座標、平方根、一次方程式、不等式の操作を前提として確認します。度とラジアンの対応は教材内で扱います。Q7で使う平方完成は未習なら補います。

知識単位はU1（座標と単位円）、U2（典型角・符号・角度単位）、U3（半径による拡大）、U4（中の角と範囲）、U5（方程式）、U6（最大・最小）、U7（単位円の関係式と二次式）です。定義は生徒用教材、到達判定は教師用方針に置きます。学習者ごとの到達状態は教材定義へ書き込まず、`Output.md`のreportへ記録します。

利用者が新しい入力を用意する必要はありません。教材の差し替え時は問題・解答・ヒント・評価の整合性を再確認します。
