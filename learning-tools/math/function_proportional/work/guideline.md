# 比例：教師用方針

教材ID：`proportional-wire` / 版：0.1（設計案）

共通方針は`../../../guideline.md`。問題・前提の正本は`../input/student-sheet.md`、成果物は`../Output.md`を参照します。導入、課題、ヒント、解答、判定基準は教材作成者による確認前です。

## 範囲と説明上の注意

同じ材質・同じ太さの針金について、長さと針金だけの重さの比例を扱います。現実の定義域は `x≧0` です。負の長さ、負の重さ、負の比例定数は固定問題に含めません。

比例は「一方が増えると他方も増える関係」ではありません。同じ倍率で変わること、`x≠0` で商 `y÷x` が一定であること、`y＝ax` と表せること、`x＝0` なら `y＝0` であることを結び付けます。

比例定数24は無単位の数字ではなく、針金1 mあたり24 g、単位は `g/m` です。`60÷2.5` と `2.5÷60` を取り違えた場合は、単位と言葉へ戻します。

容器込みの表示は、長さ0 mでも35 gなので比例しません。比較の目的は比例の成立条件を明確にすることであり、`y＝24x＋35`、切片、一次関数のグラフは指導しません。

## 6段階の進行

### 1. 知る

必ず生徒用教材の最初の問いを出し、5 mと1.25 mについて予想と理由を待ちます。式を先に教えません。

- 期待する予想：5 mは元の2倍なので120 g、1.25 mは元の半分なので30 g。
- この段階では用語の正確さより、「同じ針金なら長さと重さが同じ倍率で変わる」という見通しを確認する。
- 「長くなるから重くなる」だけなら、何倍かを問い返し、増減と比例を区別する必要を把握する。

### 2. 覚える（U1〜U3）

生徒用教材のU1〜U3を少数ずつ提示します。最初に次の3点だけを確認します。

1. 比例では二量が同じ倍率で変わる。
2. `x≠0` では `y÷x＝a` が一定。
3. 式は `y＝ax`。

その後、「比例定数は何を表すか」「針金の例で単位は何か」「x＝0ならyはいくつか」を一問ずつ確認します。言葉、式、単位を正確に再生できたら理解へ進みます。理由の導出はこの段階で要求しません。

### 3. 理解する（U1〜U4）

U1からU4を順に扱い、初回回答後に必要なら表やグラフで検証します。

- U1：長さが2倍、3倍、0.4倍なら重さも2倍、3倍、0.4倍。
- U2：`60÷2.5＝24`。単位は `g/m`、意味は針金1 mあたり24 g。
- U3：`y＝24x`。`x` と `y` の意味と単位も言わせる。
- U4：yは順に0、24、60、120、432。点は原点から同じ直線上に並ぶ。現実の場面では第1象限と原点だけを用いる。

ヒントは「元の何倍か」→「1 m分を求めるにはどちらをどちらで割るか」→「1 m分をx m分にするには」の順に出します。表、式、グラフが別々の事実ではなく同じ対応を表すと説明できれば通過です。

### 4. 応用する（U5〜U7）

- U5：`300÷24＝12.5` より12.5 m。`24×12.5＝300` で検算する。
- U6：不正解。増えるだけでなく同じ倍率、一定の商、原点の対応を確かめる必要がある。
- U7：長さと容器込みの表示は比例しない。0 mでも35 gで、表示÷長さも一定にならない。針金だけの重さを取り出せば長さに比例する。

U7で一次関数の式を作らせません。「関係する量が三つあるとき、どの二量を選ぶか」に焦点を置きます。針金だけ、容器、合計を区別でき、比例を使う部分を自力で選べれば整理へ進みます。

### 5. 整理する

固定問題Q1〜Q7を順に一問ずつ提示します。以下は教師用の要約です。

| ID | 解答・判定要点 |
|---|---|
| Q1 | 5 mは120 g、7.5 mは180 g、0.5 mは12 g。2.5 mに対する倍率と重さの倍率を対応させる。 |
| Q2 | `60÷2.5＝24 g/m`。針金1 mあたり24 g。 |
| Q3 | `y＝24x`、18 mは432 g。x・yと単位を明示する。 |
| Q4 | `300÷24＝12.5` より12.5 m。`y＝24×12.5＝300` で検算する。 |
| Q5 | 各点は `y＝24x` を満たす。xが2倍ならyも2倍で、x＝0ならy＝0。 |
| Q6 | 直ちには言えない。基本料金や固定費があれば比例しない。同じ倍率、一定の商、0に対応する値を確かめる必要がある。一次関数という用語は要求しない。 |
| Q7 | 針金432 g、表示467 g。長さと針金だけの重さは比例。長さと容器込みの表示は、0 mでも35 gなので比例しない。 |

各問で、結論だけでなく、対象の二量、倍率または商、式、単位、場面への戻しを評価します。

| 誤り | 最初のヒント | 戻り先 |
|---|---|---|
| 増えれば比例と判断する | 2倍のとき、もう一方も本当に2倍ですか | 理解（U1） |
| `x÷y` と `y÷x` を混同 | 求めたいのは1 mあたり何gですか | 覚える（U2） |
| 比例定数の単位や意味がない | 24は何1つ分の、何の量ですか | 理解（U2） |
| `y＝x＋24` など加法にする | 2 m分、3 m分は1 m分をどう増やしますか | 理解（U3） |
| 逆方向でも24を掛ける | 300 gの中に24 gが何個ありますか | 応用（U5） |
| 容器込みも比例とする | 針金が0 mなら表示は0 gですか | 応用（U7） |
| グラフが原点を通るとだけ暗記 | 原点は場面では何を表しますか | 理解（U4） |

原因が不明なら診断質問を先に行います。戻った段階の確認後、同じ整理問題でもう一度、自力で理由を再構成させます。

### 6. 人に説明する

生徒用の最終説明課題を提示し、説明終了までヒントや訂正を挟みません。終了後に次を一問ずつ確認します。

1. 「二つの量がどちらも増える」だけでは、なぜ比例と言えないのか。
2. 比例定数24の単位と意味は何か。
3. 容器込みの表示では、どの成立条件が崩れるか。

伝達の品質と教材整合性を別々に評価します。倍率、一定の商、1あたり、式、原点、適用条件が因果関係としてつながり、Q7を説明できれば十分理解です。

## 反比例教材との接続

反比例教材を実施済みの場合だけ、次を追加で比較します。

| 観点 | 比例 |
|---|---|
| 倍率 | xがk倍ならyもk倍 |
| 一定になる量 | `y÷x` |
| 式 | `y＝ax` |
| 0 | x＝0ならy＝0 |
| グラフ | 現実の範囲では原点から伸びる直線の一部 |

反比例側の記憶を前提にせず、履歴または回答で到達を確認してから比較します。
