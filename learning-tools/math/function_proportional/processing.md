# Processing：比例

Skillは、前提の再生確認、場面からの二量の抽出、倍率と商の計算、単位付き比例定数の解釈、表・式・グラフの相互変換、未知量の順方向・逆方向の計算、誤答診断、段階的ヒント、学習記録の整理です。使用順序と条件は`work/guideline.md`に従います。

表やグラフを生成する場合は、次を仕様とします。

- 横軸を針金の長さ `x`（m）、縦軸を針金だけの重さ `y`（g）とし、軸名と単位を省略しない。
- `y＝24x` について、`(0, 0)`、`(2.5, 60)`、`(5, 120)`、`(18, 432)`の対応を確認できるようにする。
- 現実の主題では `x≧0` の部分だけを表示し、負の長さを現実のデータとして扱わない。
- 容器込みの表示を比較する場合は、針金だけの重さと混同しない表示にする。比例でない理由を原点と商から確認し、一次関数の一般化には使わない。
- 図や計算結果は、学習者の初回予想後に検証用として使う。グラフを見ただけで理解済みと判定しない。
- 比例定数24には `g/m`、求めた量には `m` または `g` を付け、数値だけの一致で判定しない。

プログラムを追加する前に`Output.md`へ成果物を定義します。計算ロジックと画面制御を分離し、描画上の丸め値を正解判定に使いません。
