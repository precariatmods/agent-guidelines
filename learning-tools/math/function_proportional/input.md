# Input：比例

- 教材ID：`proportional-wire`
- 版：0.1（設計案）
- 固定教材の正本：`input/student-sheet.md`
- 指導手順・ヒント・解答・判定基準の正本：`work/guideline.md`
- 成果物：`Output.md`の各IDを参照。

到達目標は、現実の場面から比例する二量を選び、倍率、1あたりの量、一定の商、式 `y＝ax`、表、グラフを相互に結び付け、未知量を順方向・逆方向に求め、比例でない場合との違いを説明できることです。

固定する主題は「同じ材質・同じ太さの針金の長さと重さ」です。2.5 mで60 g、空の容器が35 gという数値を用います。針金だけの重さは長さに比例します。容器込みの表示は比例しませんが、一次関数として式を一般化することは学習対象外です。

対象学年は未指定です。小数の乗除、単位、座標を前提として確認します。負の長さ・負の重さは扱わず、主題の定義域は `x≧0` とします。

知識単位はU1（二つの量と同じ倍率）、U2（1あたりの量と一定の商）、U3（比例の式）、U4（表・式・グラフ）、U5（順方向・逆方向）、U6（比例かどうかの判定）、U7（現実の量から比例する部分を取り出す）です。

利用者が新しい入力を用意する必要はありません。教材の数値や題材を差し替える場合は、生徒用問題、教師用解答、ヒント、グラフ、単位、判定基準の整合性を再確認します。
