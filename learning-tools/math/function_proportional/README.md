# 比例：針金の長さと重さから考える

教材ID：`proportional-wire` / 版：0.1（教材作成者の確認前の設計案）

同じ材質・同じ太さの針金では、長さが何倍になると重さも同じ倍率になることを入口に、比例する二量、比例定数、式 `y＝ax`、表、グラフ、順方向・逆方向の計算を結び付ける教材です。

中心となる考え方は「比例する二量を選ぶ」「一方が何倍なら他方も同じ何倍」「商 `y÷x` は一定で、その値は1あたりの量を表す」の3点です。容器込みの重さは、長さが0でも0にならないため比例ではないという比較も扱いますが、一次関数の式や一般論には広げません。

対象学年は未指定です。小数の四則計算、単位、座標を扱う学習者を想定します。現実の量は `x≧0` の範囲で扱います。
