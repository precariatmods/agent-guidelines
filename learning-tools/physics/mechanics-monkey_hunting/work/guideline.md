# Monkey Hunting 学習ガイドライン

このフォルダは、モンキーハンティングを使った物理・力学の学習サンプルです。

成果物と出力先は、一つ上の階層にある`Output.md`を必ず先に確認します。保存場所を変更する場合は`Output.md`を更新します。

## 現在の教材ファイル

- `monkey_hunting(picture).py`
- `monkey.png`
- `ball.png`

小規模サンプルのため、処理方針・中間ファイル定義・確認条件は `work/` に集約します。

元の教材ファイルは勝手に上書きせず、変更や実行で生成する中間データが必要な場合は `work/` を使用します。
成果物を作る場合は、教材側で出力先を定義してから実行します。

公開前は `Localrule.md` に従い、再生成できる中間成果物を整理します。
