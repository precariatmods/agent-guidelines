# Agent Guidelines

AI自動化の組み立て方を学ぶ教育用サンプル集です。完成した業務システムとしてそのまま使うことを前提にしていません。

基本は3つです。

| ファイル | 役割 |
|---|---|
| input.md | 材料をそろえる：素材・入力条件 |
| processing.md | 処理したいことを書く：処理内容・完成条件 |
| instructions.md | 進め方を決める：順序・確認方法・停止条件 |

必要なら処理プログラムを作成・検証し、その後は検証したプログラムを使って繰り返し実行します。これらは教材独自の分類です。AIへの開始依頼で、読むファイルを指定してください。

## ダウンロード

GitHubの「Code → Download ZIP」で取得して展開してください。Gitを使う場合は次でも取得できます。

```sh
git clone https://github.com/precariatmods/agent-guidelines.git
```

最初に教材のREADMEを読み、必要な環境と開始依頼を確認してください。Gitは必須ではありません。

安全確認を希望する方は[はじめに確認すること](SECURITY.md)を参照してください。
