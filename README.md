# Agent Guidelines

このリポジトリでは、最初にこのREADMEを地図として使います。

## 地図

```text
agent-guidelines-main/
├─ video/             動画作成
├─ meeting-minutes/   音声から議事録作成
└─ learning-tools/    学習ツール
```

利用者の目的に合うフォルダを選び、そのフォルダの `README.md` を読んでください。
必要のないフォルダの詳細は最初からすべて読み込まず、選ばれた経路だけを順に確認します。
用途別の成果物と作業フォルダも、選んだトップレベルフォルダの配下へまとめます。たとえば動画作品は`video/`配下へ保存し、リポジトリ直下へ用途別の作業フォルダを作りません。

成果物を生成する各教材・ワークフローには、必ず`Output.md`を置きます。出力先を変更するときは`Output.md`を更新し、Codexは処理開始前にその内容を読んで、解決した絶対出力先を報告します。リポジトリ全体の規則は[Output.md](Output.md)を参照してください。

最初の共通安全確認は `SECURITY.md` に従います。
下位フォルダに固有の方針がある場合は、その場所のガイドラインで共通方針が具体化・追加されます。

最初の質問例：

```text
このフォルダでは何ができますか？
```

## このサンプルでの考え方

このプロジェクトでは、理解しやすくするために次の4つに簡略化して扱います。

- コネクタ = 入力
- スキル = 処理
- ポリシー = 進め方
- アーティファクト = 出力

これはこのサンプル内で理解しやすくするための整理です。正式な仕様・用語・最新情報はOpenAI公式ドキュメント等を参照してください。
