# Agent Guidelines

ガイドラインを使って、色々な処理を試す教育用サンプル集です。リポジトリ全体をダウンロードして、Codexとの会話から始めます。

## 最初にすること

1. GitHubの「Code → Download ZIP」で全体を取得する。
2. ZIPを解凍し、新しい作業フォルダへ内容をコピーする。
3. README.mdがあるフォルダをCodexで開き、次のように頼む。

```text
READMEを読んで、何ができるかと始め方を分かりやすく説明してください。
準備が必要なら、一つずつ案内してください。
```

以降は、Codexの案内に沿って選び、準備して、試します。初めから方針ファイルやプログラムの名前を覚える必要はありません。Gitで全体を取得する方法でも構いません。

## 今できること

| サンプル | 体験すること | 必要な環境 | 案内先 |
|---|---|---|---|
| 動画制作・文学紙芝居 | 台本や素材を用意し、同梱Pythonで音声を作り、Remotionで動画にする | Codex、Python 3.10以上、VOICEVOX、Node.js・npm。Remotionの準備状況は開始時に確認 | [動画教材のREADME](video/literary-kamishibai/README.md) |

現在公開しているのは動画教材だけです。音声生成プログラムは同梱しています。Remotionの構成は必要に応じてCodexが準備し、依存関係の導入は案内に沿って行います。

CSV分析やベクトルの解説などは今後追加する予定で、まだこのダウンロードには含まれていません。ここでは広く浅く試せる例を扱い、Studyの詳しい単元教材は別リポジトリで扱う予定です。

## Codexへの案内方針

利用者からこのREADMEの説明を求められたら、次の流れで案内してください。

1. 「今できること」に載っている公開済みサンプルだけを、短く説明する。予定の教材を実行可能と案内しない。
2. 利用者が試したい内容を確認する。既に指定されていれば聞き直さない。現在は動画教材から案内する。
3. 選ばれた教材のREADMEと、input.md・processing.md・instructions.mdを読み、最初の小さな体験と必要な準備を説明する。
4. 初回はSECURITY.mdがあれば実行前の確認を案内する。確認済み、または利用者が不要とした場合は繰り返さない。削除済みなら停止や再作成はしない。
5. 読み取りで分かる環境は確認し、人が必要な操作だけを一つずつ案内する。ChatGPTのプロジェクト作成、ファイル登録、出力のダウンロードは利用者の操作として説明する。
6. 説明を求められただけでは制作を始めない。開始の依頼を受けたら同梱プログラムを優先して使い、入力確認から進める。外部ソフトの導入や更新は無断で行わない。
7. 実行結果を確認し、次に行うことを短く示す。確認・停止条件は選んだ教材に従う。

案内は日本語で簡潔にし、手順を最初から全部並べず、今必要な操作を伝えてください。

## 共通の3ファイル

| ファイル | 役割 |
|---|---|
| input.md | 材料・入力条件 |
| processing.md | 処理内容・完成条件 |
| instructions.md | 進め方・確認方法・停止条件 |

まずサンプルを動かし、慣れたら方針や入力を変えて結果を確かめます。
