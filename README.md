# Agent Guidelines

ガイドラインを使って、色々な処理を試す教育用サンプル集です。リポジトリ全体をダウンロードして、Codexとの会話から始めます。

## 最初にすること

1. GitHubの「Code → Download ZIP」で全体を取得する。
2. ZIPを解凍し、新しい作業フォルダへ内容をコピーする。
3. README.mdがあるフォルダをCodexで開き、次のように頼む。

```text
READMEを読んで、まず同梱ファイルのセキュリティチェックをしてください。
その後、何ができるかと始め方を、一つずつ案内してください。
```

最初に同梱ファイルを読み取りだけで確認し、結果を短く説明します。この確認のために外部ツールのダウンロードやインストールは要求しません。その後、Codexの案内に沿って選び、準備して、試します。初めから方針ファイルやプログラムの名前を覚える必要はありません。Gitで全体を取得する方法でも構いません。

## 今できること

|---|---|---|---|
| 動画制作・文学紙芝居 | 台本や素材を用意し、同梱Pythonで音声を作り、Remotionで動画にする | Codex、Python 3.10以上、VOICEVOX、Node.js・npm。Remotionの準備状況は開始時に確認 | [動画教材のREADME](video/literary-kamishibai/README.md) |

現在公開しているのは動画教材だけです。音声生成プログラムは同梱しています。Remotionの構成は必要に応じてCodexが準備し、依存関係の導入は案内に沿って行います。

CSV分析やベクトルの解説などは今後追加する予定で、まだこのダウンロードには含まれていません。ここでは広く浅く試せる例を扱い、Studyの詳しい単元教材は別リポジトリで扱う予定です。

## Codexへの案内方針

利用者からこのREADMEの説明を求められたら、次の流れで案内してください。

1. **最初にセキュリティチェックを行う。** SECURITY.mdを参照し、同梱ファイルの一覧と内容を読み取りだけで確認する。この段階では同梱プログラムの実行、外部通信、ツールのダウンロード・インストール要求を行わない。EXE・関連バイナリの有無、秘密情報らしき記述、外部通信・ダウンロード処理、上書き・削除の処理を確認する。
2. 確認できた事実を短く報告する。例：「配布フォルダにEXEはありません」「音声生成時はローカルVOICEVOXへ接続します」「再生成では対象WAVを上書きします」。実際に確認していないことを断定せず、確認できない箇所は明記する。初回の空フォルダ使用など履歴は、現在の一覧だけで断定しない。同じ内容を確認済みなら繰り返さず、SECURITY.md削除済みでもこの項目に沿って確認できる。
3. 「今できること」の公開済みサンプルを短く説明し、試したい内容を確認する。指定済みなら聞き直さない。予定の教材を実行可能と案内しない。
4. 選ばれた教材のREADMEとinput.md・processing.md・instructions.mdを読み、最初の小さな体験と必要な準備を案内する。教材の環境準備はセキュリティチェックとは別工程として扱う。
5. 人が必要な操作を一つずつ案内する。ChatGPTのプロジェクト作成、ファイル登録、出力のダウンロードは利用者が行う。
6. 開始の依頼を受けたら同梱プログラムを優先して使い、入力確認から進める。説明だけの依頼で制作を始めず、外部ソフトの導入や更新を無断で行わない。
7. 実行結果を確認して次の操作を短く示す。確認・停止条件は選んだ教材に従う。

案内は日本語で簡潔にし、手順を最初から全部並べず、今必要な操作を伝えてください。

## 共通の3ファイル

| ファイル | 役割 |
|---|---|
| input.md | 材料・入力条件 |
| processing.md | 処理内容・完成条件 |
| instructions.md | 進め方・確認方法・停止条件 |

まずサンプルを動かし、慣れたら方針や入力を変えて結果を確かめます。
