# 会議議事録Policy

## ヘッダー確認Policy

### 目的

会議の会話内容からヘッダー項目の候補を抽出し、利用者との対話で確定する。

### 対象項目

ヘッダー項目は`template/header.csv`に合わせ、次の5項目だけとする。

1. 会議名
2. 開催日
3. 開始時刻
4. 終了時刻
5. 場所

### 対話手順

1. 全文文字起こしから、5項目それぞれの候補を抽出する。
2. 抽出した候補を一覧で提示する。
3. 候補が見つからない項目は空欄で隠さず、`不明`と表示する。
4. 一覧の後に、必ず「この内容でよいですか？」と利用者へ確認する。
5. `不明`の項目がある場合は、「ここが不明です」と対象項目を明示する。
6. 利用者が修正した場合は、修正後の一覧を再提示する。
7. 5項目すべてについて利用者の確認を得るまで、ヘッダーを確定しない。
8. 利用者が空欄のままでよいと明示した項目は、空欄として確定できる。
9. 確定後、`template/header.csv`と同じ列名・列順で`work/final/header.csv`を作成する。

### 提示形式

```text
ヘッダー候補

会議名：〇〇会議
開催日：不明
開始時刻：15:00
終了時刻：15:40
場所：小会議室

ここが不明です：開催日
この内容でよいですか？
```

### 判断ルール

- 音声で言及されたイベント開催日と、会議の開催日を区別する。
- 音声の長さを会議時間として扱わない。
- 「午後3時に会議を開始した」など明確な発言がある場合だけ開始時刻の候補にする。
- 「40分ほどの会議だった」など開始時刻から終了時刻を計算できる場合でも、計算値であることを明示して確認する。
- 会議名は議題から候補を作成できるが、確定値として扱わない。
- 日付、時刻、場所、会議名を推測だけで確定しない。
- 利用者が確認した値だけを`work/final/header.csv`へ出力する。

## メンバー確認Policy

### 目的

話者分離で検出した話者IDを、利用者との対話によって人物マスターの人物へ一人ずつ紐付ける。

### 開始時の案内

1. 話者分離で検出した話者IDの件数を数える。
2. 最初に「話者IDから〇名の候補があります」と案内する。
3. 検出人数は人物マスターの人数ではなく、音声から検出した話者IDの数とする。
4. ナレーションや音声案内と思われる話者も勝手に除外せず、利用者へ確認する。

### 一人ずつ確認する手順

1. 未確認の話者IDから一人を選ぶ。
2. その話者を判断する手掛かりとして、キーとなる会話を原則3件提示する。
3. 発言が3件未満の場合は存在する発言だけを提示する。
4. 発言は短く整えてよいが、人物を誘導するような意味の追加や書き換えをしない。
5. 発言とともに、人物マスターの人物ID、氏名、部署を候補として提示する。
6. 最後に「この話者は誰ですか？」と一人分だけ質問する。
7. 利用者が人物を選択したら、話者IDと人物IDの対応を復唱する。
8. 利用者の確認後、次の未確認話者へ進む。
9. 全話者の確認が終わるまで、この手順を一人ずつ繰り返す。

### 提示形式

```text
話者IDから4名の候補があります。

1人目：speaker_001
キーとなる会話：
- 今日は10月の体験イベントについて決めたいと思います。
- 今回は対象をはっきりさせたいですね。
- 申し込みフォームと告知掲載は私が作成します。

人物候補：
- ID 1：佐藤（総務）
- ID 5：鈴木（総務）
- ID 8：加藤（総務）
- ID 9：藤原（総務）

この話者は誰ですか？
```

### 回答の扱い

- 利用者は人物IDまたは氏名で回答できる。
- 同姓または同名の人物がいる場合は、人物IDと部署を追加確認する。
- 人物マスターに該当者がいない場合は、勝手に人物を追加しない。
- 判断できない場合は`未確認`として残し、仮話者IDを維持する。
- 「ナレーター」「参加者ではない」と回答された話者は、人物へ紐付けず、その状態を記録する。
- 同じ人物が複数の話者IDへ対応する回答も許可するが、入力誤りでないか確認する。
- 発言内容、部署、役職だけを根拠に人物を確定しない。

### 全話者確認後

1. 話者ID、人物ID、氏名、確認状態の対応一覧を提示する。
2. 未確認の話者がある場合は、「ここが不明です」と話者IDを明示する。
3. 一覧の後に「この話者対応でよいですか？」と確認する。
4. 利用者が修正した場合は、該当話者を再確認して一覧を再提示する。
5. 確認済みの対応だけを`work/final/participants.csv`と人物紐付け後の全文文字起こしへ反映する。
