# minutes.csv schema

最終列は`template/minutes.csv`を正本とします。

```csv
LineID,開始時刻,終了時刻,話者ID,発言者,議事内容
```

| 列 | 内容 |
|---|---|
| `LineID` | 元発言を追跡できるID。複数行の統合時は`;`区切り |
| `開始時刻` | 要約対象の最初の発言開始時刻 |
| `終了時刻` | 要約対象の最後の発言終了時刻 |
| `話者ID` | `speaker_001`形式の話者ID |
| `発言者` | 確認済み人物の氏名。未確認なら話者ID |
| `議事内容` | 話者本人の発言として読める簡潔な要約 |
