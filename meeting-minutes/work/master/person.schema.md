# person.csv schema

会議に関係する人物を選択するためのマスターデータです。会議参加者、主催者、司会、議事録作成者は、原則として`person.csv`の`ID`で指定します。

## 現在のファイル仕様

| 項目 | 定義 |
|---|---|
| 保存先 | `work/master/person.csv` |
| 文字コード | CP932（Windows日本語） |
| 区切り文字 | カンマ |
| ヘッダー | 必須 |

カンマ、ダブルクォートを含む値はダブルクォートで囲み、値の中のダブルクォートは2つ重ねます。

## 列定義

| 列名 | 必須 | 定義 |
|---|---:|---|
| `ID` | 必須 | 人物を一意に識別するID。重複不可 |
| `name` | 必須 | 議事録に表示する氏名 |
| `Department` | 任意 | 所属部署または役職区分 |
| `Email` | 任意 | メールアドレス |

## 参照ルール

- 人物の選択とファイル間の紐付けには`ID`を使用する。
- 議事録へ表示するときは、`ID`から`name`と必要に応じて`Department`を参照する。
- 音声から人物名を取得できた場合は、`person.csv`の候補と照合してチャットで利用者へ提示する。
- 同姓または類似名がある場合は、`Department`も提示して利用者に選択してもらう。
- 利用者の確認前に、音声だけを根拠として人物IDを確定しない。
- 該当者がマスターに存在しない場合は、勝手に追加せず利用者へ案内する。
- `person.csv`は人物マスターの正本として扱い、議事録処理から自動更新しない。

## 完成条件

- `ID`が空欄または重複になっていない。
- `name`が空欄になっていない。
- 同じ人物に複数の`ID`が割り当てられていない。
- 読み込み時にCP932・カンマ区切りとして正しく解釈できる。
