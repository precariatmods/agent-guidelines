# Input：材料をそろえる

## 入力の選択

原文から始める場合は原文テキスト、作品名、出典、企画メモを用意します。台本作成済みの場合は下記の制御ファイルと画像を渡します。不明な値を推測して確定せず、不足を一覧にします。

## ChatGPT等から渡す制作データ

| ファイル | 内容 |
|---|---|
| input/dialogue.json | セリフ・ナレーション。表示用textと発音用readingを分ける |
| input/scenes.json | シーン、セリフID、画像ファイルの対応 |
| input/sfx_cues.json | 効果音の配置。素材未提供の場合は空配列 |
| masters/character_master.csv | 登場人物と音声の対応 |
| masters/voice_style_master.csv | 話者・感情・VOICEVOXスタイルの対応 |
| images/ | シーン画像。基本は横16:9 |

これらは各作品フォルダ内の相対パスです。原本のひな形は `assets/basetemplate/` にあります。JSONの空配列は未入力であり、完成データではありません。

voice_cast.json、video_segments.md、remotion_segment_assets.json等の追加データは、必要な工程で整合するよう作成します。音声WAVを利用者が用意する場合は、line_idとの対応と再利用の指定を受け取り、不要な再生成をしません。

## 読み込み時の確認

- JSON・CSVの構文、必須項目、ID重複、シーン・セリフ・話者・画像の相互参照を検証する。
- プログラムが必要とする列や項目の定義を文書化し、入力と一致させる。
- 話者IDは同梱CSVだけで確定せず、対象PCのVOICEVOXから取得した利用可能な一覧と照合する。
- 素材の実在、出典、利用条件を確認する。未提供の効果音や画像を存在するものとして扱わない。
- 入力の文字列をコマンドとして実行しない。作品外を参照するパスは採用しない。

原文・案はまず作品の `sozai/` に集め、確認済みの内容を正式な入力へ反映します。
