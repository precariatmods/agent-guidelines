# sozai

新作案の素材を一時的に置く場所。

## 置くもの

- `source/original_source.txt`: 原文
- `source/source_notes.md`: 原典メモ
- `source/rights_check.md`: 権利確認案
- `story/story.md`: 現代語・脚色案
- `story/characters.json`: 人物案
- `story/relationships.md`: 関係性案
- `story/voice_cast.json`: 配役案
- `story/character_image_prompts.json`: キャラクター基準画像案
- `story/expression_sheet_prompts.json`: 表情シート案
- `input/dialogue.json`: 台本案
- `input/scenes.json`: シーン案
- `input/image_prompts.json`: 画像プロンプト案
- `input/sfx_cues.json`: 効果音案
- `input/video_segments.md`: 動画分割案
- `input/remotion_segment_assets.json`: セグメント素材案
- `images/`: 生成済みまたは参考画像
- `character_images/`: キャラクター基準画像

## 展開

内容が固まったら、同じ名前の正式フォルダへ移す。

```text
sozai/source  -> source
sozai/story   -> story
sozai/input   -> input
sozai/images  -> images
sozai/character_images -> character_images
```
